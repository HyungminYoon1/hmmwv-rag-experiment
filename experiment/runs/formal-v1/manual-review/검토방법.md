# 수동 검증 40개

먼저 blinded-answers.json의 답변을 읽고 evidence-guide.json 및 원본 PDF를 대조한다. 조건명과 자동점수를 보지 않은 상태에서 주장별 지원, 필수 요소 충족 또는 답변불가 부분의 유보 여부를 기록한다. 검토자의 이름·확인 날짜와 원문 위치·판정 사유를 함께 남긴다.

이 단계가 끝난 뒤 key.json에서 조건을 확인한다. 답변가능 문항의 RAG 답변 10개에 대해서는 원본 attempt 파일의 retrieval.items에 실제로 제공된 문맥을 사용하여 주장 지원 여부를 추가 확인한다. 이는 Oracle 근거 지원 판정과 구별한다. 답변의 인용 양식으로 조건을 추측할 수 있다는 한계도 기록한다.

현재 40개는 검토 대상으로 추출된 상태이며 검토가 완료된 것이 아니다. 수동 점수를 자동점수 평균에 섞지 않는다.
