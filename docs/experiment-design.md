# 실험 설계와 지표

이 문서는 배포된 실험을 읽기 위한 안내입니다. 실행별 설정·입출력은 manifest와 원본 기록을 기준으로 확인합니다.

## 연구 질문과 비교 조건

공개 HMMWV 정비교범을 검색 문맥으로 제공하면 동일한 로컬 경량 모델의 답변이 근거를 더 잘 활용하는지 확인합니다. LLM Only에는 질문만, RAG에는 질문과 Top-5 검색 문맥을 제공합니다. 생성모델과 공통 지시문은 동일합니다. 정답 근거는 검색·생성에 전달하지 않고 평가에 사용합니다.

- 원문: TM 9-2320-280-20-1, Volume 1, 1996 / Change 2 2004.
- 검색 범위: PDF 31~863쪽, 제1·2장 833쪽. 전체 PDF 890쪽을 추출한 뒤 연구 범위를 선택했습니다.
- corpus: `corpus-v6-final`, 8,344개 청크. 최대 500토큰은 Qwen 토크나이저로 센 상한이며 모든 청크가 500토큰은 아닙니다. 조건·표 행·근거 단위를 보존하는 분할 때문에 작은 청크도 있습니다. BGE가 실제 임베딩 입력을 세는 토큰 수와는 다릅니다.
- 검색: 고정 BGE-M3, CPU float32, 정규화 벡터, FAISS IndexFlatIP, Top-5.
- 생성: Qwen3-4B-Instruct-2507 Q4_K_M, Ollama, 문맥 4,096·출력 최대 512토큰, temperature 0, seed 42.
- 질의: 단일 근거 20개, 다중 근거 30개, 답변불가 10개. 개발 점검용 질문은 별도입니다.
- 수집: 각 조건을 세 번 실행한 360개 요청. 내용 평가는 첫 회차의 120개 답변, 시간 측정은 정상 완료한 반복 회차를 사용합니다.

‘단일 근거/다중 근거’는 답변에 필요한 근거 구간 수에 따른 분류입니다. 추론 단계 수를 실증한 single-hop/multi-hop 분류로 해석하지 않습니다. 답변불가는 고정한 지식원에서 질문이 요구한 답을 충분히 도출할 수 없다는 뜻이며, 관련 단어가 전혀 없다는 뜻은 아닙니다.

## 무엇을 측정했는가

| 지표 | 계산 대상과 의미 |
| --- | --- |
| 근거 Recall@5 | 답변 가능한 각 질문의 필수 근거 그룹 중 Top-5가 충족한 비율을 구한 뒤 50문항 평균. 한 그룹에는 대체 가능한 청크가 있을 수 있음 |
| 모든 필수 근거 검색 | 모든 근거 그룹을 충족한 질문 수 / 답변 가능한 50문항 |
| 질문 관련성 | 답변에서 생성한 역질문과 원 질문의 임베딩 유사도를 이용한 RAGAS 기반 점수. 정답률과 다름 |
| 정답 근거 지지율 | 답변의 실질적 주장 중 정답 근거가 지지하는 비율. 자동평가 모델이 주장과 지지 여부를 판정 |
| 필수 요소 충족률 | 질문에 요구되는 정답 요소를 답변이 충족한 비율. 근거 없는 주장 여부와 답변의 충분성을 구별 |
| 검색 문맥 충실성 | RAG 답변의 주장이 실제 전달된 검색 문맥에서 지지되는 정도. 답변 가능한 질문 중 평가 가능한 답변을 사용 |
| 답변유보 | 답변 가능한 질문에서의 유보와 답변불가 질문에서의 적절한 유보를 별도 집계 |
| 시간·자원 | 응답시간, 검색시간, 생성시간, PID별 RAM과 장치 VRAM 표본. 장비·측정 범위와 함께 해석 |

지표마다 분모가 다릅니다. 결측·해당 없음은 0점으로 자동 대체하지 않습니다. 정확한 프롬프트·예외 처리와 각 실행의 분모는 [평가 README](../experiment/evaluation/README.md)와 실행별 report/summary에 있습니다.

## 근거 개정과 검증 범위

최초 gold-v1, 1차 개정 gold-v2 및 현재 정정 gold-v3를 모두 제공합니다. [정정 내역](corrections-20260929.md)에 필수 요소·동등 근거·민감도 분석을 정리했습니다. 개정은 답변 생성 후에 이루어졌으므로, 사전에 모든 채점 기준을 고정한 실험으로 표현하지 않습니다. 생성 답변·검색 결과·응답시간은 유지하고, 정답 근거와 평가 규칙을 보완해 같은 답변을 다시 평가했습니다.

근거 대응표와 원문 캡처를 포함한 추가 검토는 Astra를 이용한 AI 검토입니다. 파일 해시·페이지·인용 구간·계산식의 프로그램 검증과 정비 전문가의 의미 검증은 별개입니다. 저장된 판정이 ‘COMPLETED’라고 해서 전문가 확인이 완료됐다는 뜻은 아닙니다.

이 실험은 제한된 교범·60문항·한 생성모델에 대한 결과입니다. 실제 정비 현장의 안전성이나 다른 장비 교범 전체에 대한 일반화는 이 자료로 측정하지 않았습니다.
