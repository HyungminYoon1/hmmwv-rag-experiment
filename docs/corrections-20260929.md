# 2026-09-29 근거 기준 정정

이번 배포는 같은 검색 결과와 같은 답변에 적용한 정답 기준을 보완한 정정본이다. 검색기·생성모델을 개선하거나 답변을 새로 생성한 결과가 아니다. 원문 대조는 Codex Astra가 수행했고, 자동 의미 판정은 기존 GPT-6 Sol 결과를 재사용했다.

## 원인과 수정

| 항목 | 원인 | 정정 |
|---|---|---|
| S16 | 의미만 묻는 질문에 오일 유입 경로까지 필수 답변으로 등록 | S16-A02를 필수 요소에서 제외 |
| S16·M06 | 의미가 완결된 청크에 선택적 설명의 다음 청크까지 AND로 요구 | C002436 단독 허용. 문장이 나뉜 C001647+C001648은 AND 유지 |
| S15·S17 | 증상별 진단 노드에 있는 동등한 시스템 식별 근거 누락 | 각각 C001838, C001993 추가. 같은 사실을 묻는 M05에도 적용 |
| M24 | 같은 조향기 장착 볼트 토크의 대체 위치 누락 | C005773 추가 |
| M01·M11 | 질문에서 측정점·발전기 용량을 명시하지 않음 | 문구를 바꾸지 않고 문항 제외 민감도 분석 |

검색 Recall은 모델 API가 아니라 등록된 충분 청크 조합으로 계산한다. S16의 Sol 입력에는 잘못된 필수 요소가 이미 포함되어 있었다. 이 문제는 기준 작성과 검토의 오류이며, API 장애나 모델이 새 필수 조건을 만들어 낸 결과가 아니다. 파일·해시·집계 검사를 통과해도 기준의 의미가 맞다는 보장은 없으며, 이번 정정 역시 독립 전문가 검토를 대신하지 않는다.

## 전후 결과

| 지표 | gold-v2 | gold-v3 |
|---|---:|---:|
| 근거 Recall@5 | 70.0% | 78.0% |
| 전체 필수 근거 확보 | 27/50 | 31/50 |
| 요소 충족률 — LLM Only | 24.8% | 25.8% |
| 요소 충족률 — RAG | 77.2% | 78.2% |
| 모든 답변 요소 충족 — LLM Only / RAG | 4/50 · 28/50 | 5/50 · 29/50 |
| 근거 지지율 — LLM Only / RAG | 18.4% · 77.7% | 동일 |

S16의 두 조건에서 불필요한 항목만 분모와 판정 목록에서 제외했다. 남은 요소의 기존 판정은 모두 1이었다. 다른 답변 판정과 관련성·충실도·유보·시간·메모리 값은 그대로다. 조건 간 요소 충족률 차이 52.4%p도 유지된다.

S15·S17의 진단 노드까지 동등 근거로 인정한 주 집계와, 명시적인 배기색 안내만 인정한 좁은 기준을 함께 제시한다. 후자는 Recall 74.0%·전체 확보 29/50이다. M01·M11을 제외한 48문항에서도 RAG의 근거 지지율·요소 충족률 차이는 각각 59.6%p·53.5%p였다. 사후 개정임을 공개하며 점수가 높아진 사실을 검색 성능 개선으로 해석하지 않는다.

## 고정 corpus의 잔여 구조 오류

PDF 153·216쪽 일부 문장의 분할·읽기 순서와 209쪽의 OCR 잡음을 확인했다. 문구가 인접 청크로 분리된 문제와 실제 소실을 구분했다. 이번 평가에 필요한 사실과 동등 근거는 원문 이미지로 대조했으며, 불완전한 C001917을 새 충분 근거로 채택하지 않았다. 전체 890쪽과 모든 청크의 의미가 완전히 검수됐다는 뜻은 아니다. corpus를 보완하면 새 버전과 검색·생성 재실험으로 검증해야 한다.
