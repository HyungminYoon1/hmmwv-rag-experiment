선택한 18,904개 원 파일의 출처 목록은 artifacts에 있습니다. 파일 해시 검사는 의미상의 전수 검토를 뜻하지 않습니다. 사용자 환경변수·`.env`의 값을 출력하거나 배포에 복사하지 않았습니다.

보관한 텍스트에서 대표적인 키·토큰 패턴도 확인했습니다. 검색된 한 항목은 외부 호출을 모의 처리하는 기존 단위 검사의 가짜 키였으며, 실제 자격 증명으로 취급하지 않았습니다. 값은 출력하지 않았습니다. 패턴 검사를 모든 종류의 비밀정보에 대한 보증으로 확대하지 않습니다. 원 질문 검증에 필요한 평가질의 HWPX 2개를 포함했습니다.

## 로컬 확인 자료

생성된 보고서는 Git에서 제외한 `validation/local/`에 있습니다. 결과·인덱스·전처리 검증 보고서는 재연 설명서의 명령으로 다시 생성할 수 있습니다. `package-audit.json`은 별도 원 연구 폴더와 비교한 이 준비본 제작 시점의 기록입니다.

- saved-results-verification.json: 실제 평가 결과·PDF 캡처 대조.
- index-verification.json: 검색 인덱스 검사.
- parse-replay.json, correction-replay.json, corpus-replay.json: 전처리 단계 검증.
- corrected-v19-a-comparison.json, corpus-v6-final-comparison.json: 재생 출력과 보존본의 파일별 해시 비교 요약.
- replay-commands.json: 전처리 재연 명령의 종료 상태.
- package-audit.json: 원본 보존, Git 포함/제외, 새 문서 링크·인코딩 검사.

새 360개 답변 수집, 유료 자동평가, 다른 PC에서의 실행, 원격 clone·Release 다운로드 검증은 이번 작업에서 수행하지 않았습니다. 현재 Git 원격 주소를 등록하거나 커밋·push·Release 업로드를 하지 않았습니다.
