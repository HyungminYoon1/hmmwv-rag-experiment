# 현재 결과와 읽는 방법

현재 기준은 **gold-v3**, 결과는 **gold-v3-formal-20260929**다. `formal-v1`의 첫 회차 120개 답변과 기존 GPT-6 Sol 판정을 사용한 정정 재집계이며 새 모델 호출은 없다. [정정 이유와 전후 비교](corrections-20260929.md)를 함께 확인한다.

| 근거 기준 | Recall@5 | 모든 필수 근거 확보 |
|---|---:|---:|
| 최초 gold-v1 | 69.0% | 26/50 |
| gold-v2 | 70.0% | 27/50 |
| 현재 gold-v3 | 78.0% | 31/50 |

단일 근거는 20/20, 다중 근거는 11/30문항에서 모든 근거를 확보했다. 다중 근거의 평균 Recall은 63.3%다. 진단 노드를 제외하는 좁은 근거 기준에서는 전체 Recall 74.0%·전체 확보 29/50이다.

| 자동평가 지표 | LLM Only | RAG | 대상 |
|---|---:|---:|---|
| 질문 관련성 | 0.7267 | 0.8411 | 답변 가능한 50문항 |
| 정답 근거 지지율 | 18.4% | 77.7% | 답변 가능한 50문항 |
| 필수 요소 충족률 | 25.8% | 78.2% | 답변 가능한 50문항 |
| 검색 문맥 충실성 | 해당 없음 | 85.2% | 평가 가능한 RAG 48문항 |
| 답변 가능한 질문의 완전 유보 | 8% | 4% | 답변 가능한 50문항 |
| 답변불가 질문의 적절한 유보 | 4/10 | 5/10 | 답변불가 10문항 |

RAG의 모든 요소 충족은 29/50, LLM Only는 5/50이다. 근거 지지율이 100%여도 필수 내용을 빠뜨린 RAG 답변은 6개다. 모든 근거를 확보한 31문항의 요소 충족률은 93.5%, 근거가 부족한 19문항은 53.2%였다. 근거 확보와 답변 충분성을 각각 확인해야 한다.

질문 관련성은 정답률이 아니며, 위 값은 고정된 질문·교범·모델의 자동평가다. 이번 원문 대조는 AI 검토이고 독립 전문가 검토는 남아 있다. M01·M11의 질문 조건을 제외한 민감도와 잔여 corpus 오류는 정정 기록에 공개했다.
