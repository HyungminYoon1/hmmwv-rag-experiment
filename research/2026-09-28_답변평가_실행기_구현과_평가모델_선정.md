# 답변 평가 실행기와 평가 모델 선정

2026-09-28. 실행기 구현과 후보 제안 기록이며 본 실험의 답변 품질 결과는 아직 없다.

## 구현

첫 회차 120답변을 평가하는 별도 환경과 CLI를 experiment/evaluation/에 추가했다. 원래 360개 생성 결과·질문·근거·검색 설정은 보존한다. RAGAS 0.4.3의 질문 관련성 및 Faithfulness 구성 요소와 연구용 추가 지표를 사용한다. 정답과 실제 검색 근거에 같은 주장 목록을 적용하고, 근거 인용과 요소별 판정을 보존한다.

최초 설치에서 langchain-community 0.4.2의 제거된 VertexAI import 문제가 재현되었다. RAGAS 소스 임시 수정 대신 호환되는 0.3.31로 고정했다. 전체 패키지 버전을 기록했다. 임베딩은 기존 검색 환경을 그대로 사용한다.

## 모델 제안

| 선택 | 후보 | 판단 |
|---|---|---|
| 상용 API, 평가 품질 우선 | GPT-6 Astra | 복잡한 조건·수치·부정 표현을 판단할 주 평가기 후보. 공식 평가 지침도 가장 강한 평가모델에서 시작해 사람의 라벨과 대조하도록 권한다. 이 교범에서 정확도가 검증된 것은 아니다. |
| 상용 API, 비용 고려 | GPT-6 Sol | 같은 API·구조화 출력을 쓸 수 있는 저비용 후보. Astra와 동등한 채점 정확도를 확인했다는 뜻은 아니다. |
| 로컬 신규 설치 | Gemma 4 12B (`gemma4:12b`) | 생성용 Qwen과 다른 계열의 12B 후보. 설치·속도·판정 품질은 아직 미검증. |
| 현재 설치 모델 | Qwen3-4B-Instruct-2507 Q4_K_M | 실험 서버에 확인된 유일한 모델. 연결 점검에는 사용 가능하나 같은 생성모델이므로 독립적인 주 평가기로 권하지 않는다. 실행기에서 가상 사례에만 허용한다. |

현재 PC는 64GB RAM, RTX 4070 Laptop 8GB GPU다. Google이 제시한 Gemma 4 12B Q4_0의 약 6.7GB는 문맥용 KV cache를 제외한 근삿값이다. Ollama 배포 파일 크기는 약 7.6GB다. 서로 다른 수치이며 8GB GPU에 여유 있게 전부 올라간다고 단정할 수 없다. CPU에 일부 계산·모델을 나누어 올려야 할 수 있다. 설치 후 가상 사례로 지연시간·문맥 처리와 출력 형식을 먼저 검증해야 한다.

2026-09-28 공식 Standard 가격은 텍스트 100만 토큰당 Astra 입력 $10 / 출력 $50, Sol 입력 $2 / 출력 $10이다. 캐시·추론 토큰·재시도에 따라 실제 비용이 달라진다. 120답변의 기본 호출은 770회로 나뉘므로 120회 호출이라고 계산하면 안 된다. 실제 사용량을 보기 전 총액을 확정하지 않는다.

API 후보 프로필은 reasoning effort=medium, 출력 상한 8,192로 준비했다. Gemma 후보는 문맥 32,768, 출력 상한 4,096, temperature=0, seed=42, thinking=false다. 선택 후 별도 가상 사례로 동작을 확인하고 고정한다. 최종 60문항의 점수를 보고 유리한 모델을 선택하지 않는다.

외부 API는 필수가 아니다. 상용 API를 선택해도 실험 대상 정비지원 시스템의 검색·생성은 로컬이다. 실험 기록에는 로컬 시스템과 사후 외부 평가모델을 구분해 기재한다. 코드에 마련한 후보 설정이 사용자의 최종 모델 선택을 의미하지는 않는다.

## 검증과 다음 단계

자동 테스트, 설치 검사, 로컬 가상 사례 실행 결과와 원자료 보존 검사는 experiment/evaluation/verification.json에 기록한다. 가상 사례의 결과는 구현 점검이며 최종 60문항의 성능이나 평가기의 일반적 신뢰도를 입증하지 않는다. 실패한 초기 가상 사례 실행도 삭제하지 않는다.

API 키가 없어 상용 API 호출·계정 모델 접근 검증은 NOT_RUN이다. Gemma는 NOT_INSTALLED / NOT_RUN이다. 본 평가도 NOT_RUN이다. 모델 선택 → 별도 검증 사례 점검 → 설정 고정 → 120답변 평가 → 기존 40개 수동평가와 대조 순으로 진행한다. 정답 근거에 대한 연구자의 원문 확인도 남아 있다.
