557건은 205개 PDF 페이지에 걸쳐 있다. 실험 범위 안의 후보는 514건, 범위 밖 후보는 43건이다. 범위 밖 자료도 감사용 기록에는 보존했다.

194 + 5 + 3 = 202개 후보에 문자 수정이 있었다. 한 후보의 native와 OCR을 각각 고치거나 여러 구간을 나눠 고칠 수 있으므로 **269건은 수정 기록 수이며 독립적인 오류 개수나 오류율은 아니다.**

예를 들어 로마숫자 `III`, 글머리표, 제목에 겹쳐 인쇄된 글자, 빠진 제목 끝의 `S`, OCR이 잘못 읽은 `3 mm` 등을 원문에 맞췄다. 원문 자체에 보이는 `4.9 voits`, `109 minutes`, `da-energized`와 PDF 830쪽 시험번호 `39`는 추정해서 바꾸지 않았다.

native 텍스트층이 항상 완전한 것은 아니다. 일부 페이지에는 참조문만 텍스트층에 있고 본문은 이미지로 들어 있다. 따라서 **페이지 전체를 native 또는 OCR 중 하나로 일괄 선택하지 않고, 이번에 대조한 구간에 한정해 채택 규칙을 기록**했다.

## 원문이 끊긴 부분의 재검토

PDF 117~119쪽의 화면을 다시 확인하고 118쪽의 문자층·열 위치를 대조했다.

- **`Metal particles are`**: PDF 118쪽의 정비 불가 판정 열에 이 구절만 남아 있다. 이번 PDF에서는 뒤 내용을 확인할 수 없어 그대로 보존했다. native·OCR·PMCS 셀의 해당 구간 3곳을 `SOURCE_INCOMPLETE`로 표시하고, 그것만으로 충분한 답변 근거로 삼지 않도록 기록했다.
- **`Change fluid every 12,000 miles`**: “12,000마일마다 유체를 교환하라”는 명령문으로 성립한다. 이 표현까지 끊긴 문장으로 함께 판단한 이전 설명을 정정했다.

118쪽 전체를 제외하지는 않는다. 위 불완전한 구절과 정상적인 절차·주의 사항을 구분했다. 다른 판본의 내용을 끼워 넣거나 누락 부분을 추론해 완성하지 않았다. 자세한 위치와 판정은 [source118-review.json](review-557/verified-v4-a/source118-review.json)에 있다.

## 재실행

프로젝트의 `preprocessing` 폴더에서 실행한다. 출력 경로는 아직 없는 새 이름을 사용한다.

```powershell
.\.venv\Scripts\python.exe -X utf8 .\correct_extraction.py --ledger .\corrections\batch-004\correction-log.json --output .\output\corrected-v4-c
.\.venv\Scripts\python.exe -X utf8 .\verify_corrections.py .\output\corrected-v4-c --ledger .\corrections\batch-004\correction-log.json --report .\audit\corrections-v4-c.json
.\.venv\Scripts\python.exe -X utf8 .\build_review557_structures.py --output .\review-557\verified-v4-c
.\.venv\Scripts\python.exe -X utf8 .\verify_review557.py
```

구조 프로그램은 보관된 `output/corrected-v4-a`와 이번에 고정한 판정 파일을 입력으로 사용한다. 마지막 명령은 고정된 a·b 결과와 백업을 종합 검사하며, 임의의 c 폴더를 검사하는 명령은 아니다. 수정 후보를 Codex로 다시 생성하는 과정이나 원본 PDF부터 OCR을 새로 수행하는 과정의 동일성까지 보장하지 않는다.

검증 프로그램 첫 실행에서는 검토 전후에 달라지는 상태값과 수정 ID까지 불변 필드로 비교하여 실패했다. 상태·수정 ID는 별도로 검증하고 원문·위치·이미지 필드는 그대로 비교하도록 검사 코드를 고친 뒤 위 검사를 통과했다. 첫 실행 기록은 `audit/review557-first-verifier-status-check.json`에 남겼다.
