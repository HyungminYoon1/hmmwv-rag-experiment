# 전체 교범 파싱 실행 방법

이 문서는 규칙 기반 파싱 단계의 실행 방법이다. 이후 Codex가 확인한 추출 오류 51건을 별도 보정본에 반영하고 프로그램으로 수정 이력을 검사했다. 최신 보정본과 명령은 [PDF 텍스트 추출 오류 보정](PDF_텍스트_추출_오류_보정.md)을 참고한다. 기존 `full-manual-v2-a`는 보정 전 추출 자료로 보존한다.

원본 PDF 890쪽 전체의 텍스트와 좌표를 읽는다. 이미지가 있는 모든 페이지, 원래 텍스트가 적은 벡터 선·도형 포함 페이지, 문자 매핑이 깨진 페이지에는 OCR 추출본을 함께 보관한다. 제1·2장인 PDF 31~863쪽은 `in_scope=true`, 그 밖의 57쪽은 `false`로 표시한다. 범위 밖에는 표지·목차·색인·서식과 접지형 도면 등이 있다.

검색 범위를 평가질의의 정답 부분으로 줄이지 않는다. 프로그램은 평가질의 파일을 읽지 않는다. 표지·목차·색인까지 검색에 포함해야 공정한 것은 아니며, 사전에 정한 범위 전체를 같은 규칙으로 처리한다.

## 결과 확인

- `output/full-manual-v2-a/교범_전체_추출텍스트.txt`: 전체 890쪽의 원래 텍스트와 OCR 결과, 열 이름을 붙인 PMCS 표를 모은 대조용 파일.
- `output/full-manual-v2-a/실험범위_본문과표_검토본.txt`: 검색 범위 833쪽의 같은 자료.
- `output/full-manual-v2-a/page_coverage.jsonl`: 모든 페이지의 처리 여부, 문자 수, OCR 여부와 검토 표시.
- `output/full-manual-v2-a/review_signals.jsonl`: 낮은 OCR 신뢰도, 단위 오인식 가능성 등 검토할 위치. 오류가 확정됐다는 뜻은 아니다.
- `output/full-manual-v2-a/pmcs_rows_as_text.jsonl`: 열 이름과 셀의 원문을 연결한 표 텍스트. 행 간 연결과 주의사항은 검수 전이다.
- `output/full-manual-v2-a/원문대조.html`: 원본 이미지와 추출 내용을 나란히 보는 표본 16쪽.

두 텍스트 파일은 읽고 비교하기 위한 자료다. 원래 텍스트와 OCR이 일부 중복되므로 이 파일 전체를 그대로 임베딩하지 않는다. 검수 후 채택한 본문·표 행을 기준으로 청크를 만든다. 그림의 화살표·연결 관계는 OCR 문자만으로 확정하지 않는다.

## 같은 입력에서 다시 실행

아래 명령은 현재 PC의 PowerShell에서 실행한다. 출력 폴더는 새 이름이어야 한다.

```powershell
Set-Location -LiteralPath '<PROJECT_ROOT>\preprocessing'
.\.venv\Scripts\python.exe -X utf8 .\parse_full_manual.py --snapshot .\assets\ocr-full-manual-v2 --output .\output\full-manual-v2-c
.\.venv\Scripts\python.exe -X utf8 .\verify_full_manual.py .\output\full-manual-v2-a .\output\full-manual-v2-c --report .\audit\full-manual-v2-compare-a-c.json
```

원본 PDF를 다시 읽고 OCR 대상 이미지를 다시 렌더링한다. 이미지 해시가 고정 추출본과 일치할 때만 OCR 문자를 재사용한다. 그 뒤 정리·표 열 추출·품질 신호 검사·텍스트 파일 생성을 다시 실행한다.

이 재현 방식에서는 OCR 결과가 고정된 입력 자료다. OCR을 새로 계산해도 모든 문자가 같다는 뜻은 아니다.

## OCR을 추가 또는 새로 계산

```powershell
.\.venv\Scripts\python.exe -X utf8 .\parse_full_manual.py --snapshot .\assets\ocr-snapshot --capture-missing-ocr --output .\output\full-manual-new-capture
```

기존 501쪽의 OCR은 출처와 픽셀 해시를 검사해 재사용하고, 새 규칙에서 추가된 페이지를 OCR한다. 결과의 `ocr-snapshot` 폴더가 이번 실행의 전체 OCR 추출본이다. 새로운 추출본을 채택할 때는 다른 버전 폴더에 보관하고 재실행 비교도 새로 수행한다.

`--extend-snapshot-only` 옵션은 전체 원문을 검사하되 기존 추출본에 없는 OCR만 추가해 새 추출본 폴더를 만든다. 이후 일반 실행에서 전체 PDF를 다시 파싱하고 모든 OCR 입력 이미지의 해시를 확인한다. `assets/ocr-full-manual-v1`은 초기 698쪽 추출본, `assets/ocr-full-manual-v2`는 문자 매핑 오류 4쪽까지 보완한 최종 702쪽 추출본이다. 현재 확인할 산출물은 `output/full-manual-v2-a`다.

## 보정 기준

원래 문장·수치·단위·부정어를 LLM으로 일괄 재작성하지 않는다. OCR의 오인식은 원문에서 확인한 수정 전후·페이지·좌표를 보정 목록으로 기록하여 수정한다. 표의 열 관계나 도면의 의미가 불명확하면 검토 대상으로 남긴다.

프로그램이 사용하는 것은 일반 OCR과 규칙 기반 처리다. 실행 시 생성형 AI API나 LLM을 호출하지 않는다. 현재 파일은 최종 실험 corpus가 아니라 검수용 추출 자료이며, 전체 문자 정확도를 보증하는 자료가 아니다.
