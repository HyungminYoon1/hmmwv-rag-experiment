# 표본 원문 대조 기록

작성일: 2026-09-22. PDF 순번은 1부터 센다. 이미지의 내용을 프로그램이 자동으로 이해했다고 주장하는 자료가 아니라, 원본 렌더링과 실제 추출 결과를 대조한 기록이다.

| PDF 순번 | 원문에서 확인한 내용 | 추출 결과와 판단 |
| --- | --- | --- |
| 61 / 1-31 | Table 1-2에 Standard/Metric 열, Crankcase Only·Crankcase and Filter의 서로 다른 값, 차종 조건이 있다. | 문자는 직접 추출된다. 열과 차종 조건을 묶은 최종 표 행은 아직 확정하지 않았다. 값만 순서대로 나열한 문장을 최종 근거로 사용하면 안 된다. |
| 97 / 2-6 | 정비 점검표의 항목 1·2·3과 절차·운행 불가 조건이 이미지에 있다. | 원래 텍스트층의 본문은 84자뿐이다. OCR로 본문을 복원하지만 항목 1의 번호에 `i`가 추가되는 등 잡음이 남는다. 등록한 행의 `item`과 OCR의 `ITEM NO.`를 구분해 보관한다. |
| 100 / 2-9 | 항목 7의 PROCEDURES에 `Do not clean CDR valve with solvent.`가 있고, 별도 열에 CDR 진공시험 실패 조건이 있다. | 직접 추출한 열별 결과에서 두 내용을 분리해 보존했다. 위쪽 NBC 경고의 항목 연결은 별도 확인 대상으로 남겼다. |
| 103 / 2-12 | 항목 10·11, 제동장치 설명, MIL-B-46176 주의사항, 1/8 inch (3.2 mm) 기준이 있다. | OCR은 많은 본문을 복원하지만 항목 10의 운행 불가 조건에 오인식이 크다. 셀 가장자리의 일부 글자도 다시 확인해야 한다. 현재 결과는 검수 전이며 자동 채택하지 않는다. |
| 111 / 2-20 | 타이어 점검과 90-110 lb-ft (122-149 N·m) 체결값, 회전·체결 순서 그림이 있다. | 숫자는 복원되지만 `lb-ft`가 `Ib-ft`로 인식된다. 등록한 그림 영역은 셀 OCR에서 제외했다. `as diagram shows`와 `tightening sequence shown`이라는 실제 지시문은 남겼으므로 그림 의존성을 별도 판단해야 한다. |
| 180 / 2-93 | 회로 연결이 중심인 도면이다. | 원래 텍스트층만으로 도면 내용이 복원되지 않는다. OCR 문자만으로 연결 관계를 확정하지 않는다. |
| 239 / 2-155 | 냉각계 설명 본문과 ETHYLENE GLYCOL MIXTURE TABLE이 함께 있다. | 본문은 직접 추출된다. 아래 혼합표는 `OTHER_TABLE_LAYOUT_REVIEW_REQUIRED`로 표시했다. 최종 열 구조는 아직 확정하지 않았다. 이 표시가 있는 목록은 모든 표를 탐지한 결과는 아니다. |
| 500 / 2-394 | 등화 회로도와 이미지 안의 지시문이 있다. | 원래 텍스트층의 문서번호·쪽번호만으로 본문 추출 성공이라고 볼 수 없다. OCR은 문자 확인용으로만 사용한다. |
| 570 | 렌더링 결과가 빈 페이지다. | 텍스트 0, 이미지 0과 일치한다. OCR 실패로 분류하지 않는다. |
| 610 / 2-508 | YES/NO 화살표와 진단 상자가 있는 고장진단도다. | 원래 본문 46자에서 OCR 1,428자로 증가한다. 글자 수 증가가 절차 분기 복원 성공을 의미하지 않는다. |
| 810 / 3-710 | 제2장 범위지만 원본 하단에 `3-710`이 인쇄되어 있다. | 확대 원문과 대조했다. 원래 표기를 보존하고 `UNEXPECTED_PRINTED_CHAPTER_NUMBER`로 표시했다. 임의로 `2-710`으로 교정하지 않았다. |
| 860 / 2-763 | GO-Chain 검사, CAUTION, 계기 화면과 YES/NO 경로가 있다. | OCR은 글자를 읽지만 VTM 등의 약어 오인식과 그림의 의미 해석 문제가 남는다. 분기 절차를 일반 문단으로 확정하지 않는다. |

자동 원문 대조 HTML에는 주요 표본 18쪽의 원본 PNG와 추출 결과를 함께 넣었다. PDF 810쪽 하단의 추가 확대 자료는 `audit/p810-footer.png`에 있다. 위 기록은 전체 890쪽의 수동 검수나 문자 오류율 측정 결과가 아니다. 평가질의의 문구가 발견되더라도 필수 조건·단위·적용 차종이 모두 올바르게 연결되어 있는지 별도로 확인해야 한다.
