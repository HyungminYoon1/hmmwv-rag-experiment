# 그림과 텍스트의 처리 원칙

적용 범위는 기존과 같이 PDF 31~863쪽(833쪽)이다. 이 문서에서 그림을 제외한다는 것은 해당 페이지를 통째로 제외한다는 뜻이 아니다.

## 검색에 사용하는 내용

- 일반 본문, 제목, 경고, 주석, 절차와 시험 방법을 포함한다.
- 스캔 이미지에 들어 있어도 독립적으로 읽을 수 있는 설명문과 표는 포함한다. 표의 값은 행·열 이름 및 적용 조건과 함께 보존한다.
- 진단 흐름도의 질문, 시험 방법, 알려진 상태(KNOWN INFO), 가능한 원인(POSSIBLE PROBLEMS)은 서로 다른 역할로 보존한다. 가능한 원인을 확정된 고장으로 바꾸지 않는다.
- 수정은 PDF에 실제로 보이는 문구를 복원하는 데 한정한다. PDF 자체의 오탈자·불완전한 문장·이상한 수치는 별도 기록하고 임의로 고치지 않는다.

## 그림에 의존하는 내용

배선의 연결, 부품의 위치·형상, 화살표 경로, 계기의 그림 표시를 LLM이 해석한 설명문으로 추가하지 않는다. 원본 PDF와 페이지·영역 좌표를 보존한다. 그림의 일부인 식별자나 OCR 잡음은 일반 설명문과 합치지 않는다.

그림 안의 설명문을 보존했다는 사실만으로 그림의 관계까지 복원한 것은 아니다. 이런 단위에는 `graphic_dependency`와 관계 처리 상태를 기록한다. 독립적으로 의미가 완성되는 문장은 그림 옆에 있다는 이유만으로 제외하지 않는다.

YES/NO에 따른 조치 연결은 PDF에서 확인하여 별도 계약으로 기록한 경우에만 연결한다. 그 밖의 화살표는 `PDF_ONLY`로 남기며, 연결 순서나 가까운 위치만으로 조치를 특정 질문의 답으로 삼지 않는다. 확인된 연결에도 원문의 질문과 분기 표식을 유지한다.

질문과 조건의 대응이 텍스트·박스 배치만으로 하나로 정해지지 않는 곳은 각각의 문구를 독립 단위로 보존한다. 이 경우 `NO_UNREVIEWED_CROSS_BOX_INHERITANCE`와 그림 의존 상태를 기록하며, 누락된 조건을 추정해 붙이지 않는다. 원문의 POSSIBLE PROBLEMS가 빈칸이면 빈칸 그대로 둔다.

50쪽 명판처럼 원본 자체에서 수치가 희미하거나 비어 있는 경우에도 값을 복원해 넣지 않는다. 읽을 수 있는 지시문은 검색에 포함하고, 나머지는 원본 위치와 원문 결함 기록으로 남긴다.

## 조건과 페이지 경계

조건 박스의 끝은 실제 테두리로 정한다. 다음 제목이 나오기 전까지를 무조건 같은 조건으로 읽지 않는다. 조건 아래의 REPLACE, GO TO, END OF TEST 같은 문구는 조건 본문에서 분리한다.

마주 보는 참고 페이지의 설명이나 경고는 적용 대상이 확인된 경우에만 해당 질문에 연결한다. PDF 내부에 남아 있지만 화면에서 가려진 텍스트는 원문 본문으로 채택하지 않는다. 다만 좌표만 어긋난 경우에는 문구의 실제 위치를 확인하여 좌표를 고친다.

## 평가와 고정

그림의 연결이나 위치를 해석해야만 풀 수 있는 질의는 텍스트만 사용하는 평가에서 별도로 구분한다. 이를 곧바로 “교범에 답이 없는 질의”와 동일하게 취급하지 않는다. 평가질의의 근거는 corpus 고정 후 원본 PDF와 대조한다.

정상 항목의 검토 표시는 적용 규칙·출처·검증 근거를 기록한 뒤 해제한다. 해제 기록은 삭제하지 않는다. 미해결 문자 선택이나 구조 판정이 남은 동안은 후보 corpus이며, 실험용 확정본으로 표시하지 않는다. 기계 검증 통과와 PDF의 모든 문자를 사람이 검수했다는 주장은 구별한다.

고정 여부는 이번 연구의 텍스트 범위에서 판단한다. 그림 관계를 텍스트로 해석하지 않기로 확정한 항목은 처리 범위가 정해진 항목이며, 해결하지 못한 문자 선택과 같은 보류 상태로 집계하지 않는다. 검토 기록에는 Codex의 PDF 대조와 프로그램 검사 범위를 남긴다. 고정 후 오류가 발견되면 기존 결과를 덮어쓰지 않고 새 버전으로 수정하며, 그때 사용한 검색·평가 결과도 입력 버전과 함께 관리한다.
